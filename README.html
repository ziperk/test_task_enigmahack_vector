Отборочное задание

Как понять, зачем пишет абонент?

Вам предстоит разобрать 150 сообщений поддержки. Абонент может описать сбой, попросить вернуть деньги или просто написать «Да». Для каждой реплики определите, с чем человек обратился и каким должен быть следующий шаг агента. Доступ к системам оператора для задания не требуется.

1. Разметка

до 70 баллов

Прочитайте intents.md. В нём описаны 15 намерений, возможности агента и правила выбора между похожими темами. В messages.csv находятся обращения из чата. По данным организаторов, ФИО и телефонные номера заменены вымышленными. Доли в справочнике относятся к потоку обращений, состав конкурсной выборки может отличаться.

Скопируйте sample_submission.csv в submission.csv и заполните по одной строке для каждого ID. В шаблоне 150 строк с пустыми полями. Сохраните CSV в UTF-8 с заголовком id,intent_id,decision и запятой в качестве разделителя. Порядок строк свободный.

ПолеЧто вписать
idИсходный идентификатор от m001 до m150
intent_idЦелое число от 1 до 15 либо 0, если тему нельзя определить или её нет в списке
decisionself — агент справится в рамках своих полномочий, clarify — нужно уточнить запрос, handoff — нужен оператор

Например, для отдельной учебной реплики «Сколько рублей осталось на счёте?» строка выглядела бы как demo,15,self. Учебную строку в ответ включать не нужно. При метке 0 выбирайте следующий шаг по смыслу. Если вопрос понятен, но выходит за возможности агента, передайте оператору. Если человек написал только приветствие, уточните запрос.

Можно размечать вручную, применять правила, классификатор, языковую модель или сочетать методы. В 2–3 предложениях опишите, как получили и проверили результат. Исходный код можно приложить ссылкой.

2. Когда нужен человек?

до 30 баллов

Выберите два намерения, при которых ошибочное самостоятельное действие агента особенно опасно. Для каждого назовите номер, приведите конкретную ситуацию, объясните последствия ошибки и проведите границу между тем, что агент может сделать сам, и тем, что должен решить оператор. Учитывайте полномочия агента из справочника.

Лимит общего ответа на этот вопрос — 1000 знаков с пробелами. Описание метода из первой части в лимит не входит. Ответ и описание метода можно прислать в одном текстовом файле.

Как подвести итог

Скрипт сопоставляет строки по ID и считает F1 для каждого из 16 классов, включая 0. Среднее этих значений умножается на 70. Пропущенная строка, пустая или некорректная метка считается ошибкой даже для класса 0. Повтор ID или посторонний ID нужно исправить. Поле decision обязательно для каждой присланной строки и служит для обратной связи. Оно не меняет балл и место при равенстве баллов.

Представитель МОТИВ оценивает выбор двух рискованных намерений с учётом полномочий агента (10 баллов), объяснение рисков (10), границу ответственности (6), конкретность и соблюдение лимита (4). Сумма за две части — до 100 баллов.

Что сдавать

  1. Файл submission.csv.
  2. Короткий ответ и описание метода.

Срок, часовой пояс, канал отправки и формат участия уточняйте в объявлении организаторов. Проходной порог организаторы определят после проверки всех работ.
